# DatabookService

DatabookService — сервис для централизованного импорта и управления табличными справочниками (Excel / CSV).

## Ключевые возможности

- **Полный контроль создания и администрирования справочников через удобный пользовательский интерфейс.**
- **Произвольное количество столбцов и произвольные типы полей**
- **Собственнй сервис для авторизации через API-ключи**
- **Логирование всех процессов**
- **Импорт и экспорт данных в csv**
- **Возможность встраивания/интегрирования сервиса в существующие информационные системы.**

## Архитектура

- **Clean совместно с vsa архитектурой и minimal API**

## Стек технологий

- **.NET8 / ASP.NET Core**
- **PostgreSQL 15+**
- **Entity Framework**
- **Serilog + seq**
- **React 18**
- **Custom fetch wrapper**
- **Nginx**
